# An incident review desk without a front end

The useful work here is reviewing evidence, assigning follow-ups, finding repeated incidents and producing an internal review pack. Ask Claude Code, Codex, OpenCode or Cursor to run the same CLI. Read-only HTML shows the review queue, corrective actions and service history. `brand.json` sets the business name, logo and colours.

This base does not page engineers, ingest live alerts, record calls, synchronise Slack, host a public status page or run an always-on service. A phone app gives responders push notifications and a usable mobile incident room. A live screen shows changing state across people; an HTML snapshot does not. Keep the service that handles urgent response. Enterprise DNA can build and operate agreed screens and connections for your version after defining availability and access requirements.

Generated pages are internal records, not a web application. Do not publish them with sensitive evidence. The base is one business with trusted operators; it has no per-person roles. A shared deployment needs individual access, backups, restore checks, retention controls and monitoring. Agent subscriptions, hosting and operations still cost money.
