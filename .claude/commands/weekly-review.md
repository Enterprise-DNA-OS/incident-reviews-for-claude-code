# weekly-review

Run `npm run incidents -- review-queue --json`, `npm run incidents -- follow-ups --json` and `npm run incidents -- service-health --json`. Then run `npm run incidents -- compliance --json`. Write the Monday review from these results: incident owners, overdue reviews, corrective actions, services that keep failing and evidence gaps. `weekly-review --json` returns the same four sections together. Distinguish incomplete data from successful resolution. Never send the review.
